# Plan 01-03: Day 1 Verification Spikes (AI, MapLibre & Speech Fallback) & Evaluation Benchmark Harness

## Objective
Deliver the Day 1 verification spikes (headless API routes and visual `/spike` playground for Google AI Studio candidate generation, MapLibre OpenFreeMap tile rendering with latency telemetry, and ElevenLabs / Web Speech API fallback verification) and implement the isolated `/eval` benchmark dashboard with a 30-fixture manifest scoring accuracy (≥70%) and refusal rate (≥90%).

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Day 1 Spikes (D-01):** Deliver both headless API routes (`/api/spike/ai`, `/api/spike/map`, `/api/spike/speech`) and visual playground page at `/spike` with MapLibre canvas, AI candidate runner, and Speech fallback tester.
- **Key Auto-Detection (D-02):** If `GOOGLE_GENERATIVE_AI_API_KEY` is present, call Google AI Studio; if missing, return mock candidate fixture with clear UI warning banner, preventing developer blockage.
- **Speech Fallback Spike:** Verify ElevenLabs API key availability via `/api/spike/speech`. If absent, gracefully report speech fallback status. Verify browser Web Speech API capability (`webkitSpeechRecognition` for STT and `speechSynthesis` for TTS) with test execution in `components/speech/spike-speech-runner.tsx`.
- **Vision Fallback:** Gemma models lack vision input. If an image is provided, automatically fall back to Gemini Flash (`IDENTIFY_MODEL_ID="gemini-2.0-flash"`).
- **Map Telemetry (D-03):** Mount OpenFreeMap Liberty style (`https://tiles.openfreemap.org/styles/liberty`), listen to `load` event, and report style load latency and tile status badge.
- **Eval Fixtures (D-09):** Store 30 fixtures at `public/eval-fixtures/` with `fixtures.json` manifest (10 plants, 6 birds, 6 insects, 4 non-organisms, 4 people).
- **Eval Dashboard (D-10, EVAL-01):** Visual fixture card grid on `/eval` with "Run Batch" trigger button, progress bar, top-3 accuracy, refusal rate, and latency metrics.
