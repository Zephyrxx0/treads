# Plan 01-01: Next.js 16.4 Scaffolding, Tangerin Dream Tokens, shadcn Base UI Suite & Theme Toggle

## Objective
Establish the foundational Next.js 16.4 application shell with React 19.3 and Tailwind CSS v4, configure exact Tangerin Dream design tokens with zero-FOUC theme switching, install the shadcn Base UI component suite (`@base-ui-components/react`), and implement motion accessibility honoring `prefers-reduced-motion` and tab visibility changes.

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Framework:** Next.js 16.4 (App Router, Cache Components, Agent features, Lazy dynamic imports) + React 19.3 + Tailwind CSS v4
- **Theme:** Tangerin Dream CSS variable tokens strictly in `app/globals.css` with zero-FOUC head script (D-07)
- **Component Registry:** shadcn Base UI (`@base-ui-components/react`). Strictly DO NOT build components from scratch (D-08).
- **Icons:** Lucide icons (`lucide-react`)
- **Theme Toggle:** `@toggles/within` / `@theme-toggles/react` animated SVG toggle

   <script
     dangerouslySetInnerHTML={{
       __html: `
         (function() {
           try {
             var stored = localStorage.getItem('treads_theme');
             var systemDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
             if (stored === 'dark' || (!stored && systemDark)) {
               document.documentElement.classList.add('dark');
             } else {
               document.documentElement.classList.remove('dark');
             }
           } catch (e) {}
         })();
       `,
     }}

2. Scaffold shadcn Base UI components in `components/ui/` (per strict library rule D-08):
   - `button.tsx`: Button with variants (`default`, `secondary`, `destructive`, `outline`, `ghost`, `link`) and sizes (`sm`, `md`, `lg`, `icon`), mapped to Tangerin Dream colors.
   - `card.tsx`: Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter utilizing `--card` and `--card-foreground`.

   - `badge.tsx`: Badge with variants (`default`, `secondary`, `destructive`, `outline`, `success`, `warning`).
   - `sheet.tsx`: Slide-out panel built on Dialog primitive for bottom sheets and drawer menus.
   - `progress.tsx`: Base UI Progress component utilizing `--primary` track bar.
3. Implement `components/ui/theme-toggle.tsx`:
   - Animated SVG theme switch modeled after `@toggles/within` / `@theme-toggles/react`.
   - Uses `localStorage.getItem('treads_theme')` and toggles `.dark` class on `document.documentElement`.
   - Emits custom `themechange` event so client components can synchronize if needed.
   - Fully keyboard accessible (`aria-label="Toggle theme"`).
4. Implement motion accessibility (DSGN-02):
   - Create `hooks/use-reduced-motion.ts`: hook detecting `(prefers-reduced-motion: reduce)` and browser tab visibility changes via `visibilitychange` event.
   - Create `components/motion/motion-view.tsx`: wrapper leveraging `motion/react` that downgrades transform/scale animations to gentle opacity fades when `prefers-reduced-motion` is active, and pauses looping animations when `document.hidden === true`.
5. Implement preview kitchen-sink page on `app/page.tsx`:
   - Renders header with Tangerin Dream logo, theme toggle button, and status badges.
