# Plan 05-02: Activity Heatmap, Walk Detail Replay, Obsidian ZIP Exporter & Settings Data Management

## Objective
Deliver complete historical expedition exploration and data sovereignty: build the `/journal` timeline with rolling 12-week activity heatmap (`JOUR-01`), the `/journal/[walkId]` inspection page with MapLibre route replay and safe deletion (`JOUR-02`), the full Obsidian-compatible JSZip archive exporter (`EXPT-01`), and the dedicated `/settings` page with two-step Danger Zone data wipe (`SETT-01`).

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Dependencies:** Install `jszip` and `@types/jszip` using `pnpm add jszip && pnpm add -D @types/jszip`.
- **Design Contract:** Follow Tangerin Dream tokens, 4-multiple spacing scale, 4 font sizes, and reserved accent usage in `05-UI-SPEC.md`.
- **Locked Decisions (per CONTEXT.md):**
  - **D-09:** Rolling multi-week activity grid (12 weeks, 7 days high) with 4 terracotta intensity levels based on mileage and find count.
  - **D-10:** Chronological date-grouped walk timeline with rich summary cards.
  - **D-11:** Split inspection layout for `/journal/[walkId]` with MapLibre header map (route polyline + specimen/audio pins) and tabbed details.
  - **D-12:** Editable walk title and safe delete confirmation prompt offering to preserve confirmed finds in Life List or purge entirely.
  - **D-13:** Structured Naturalist Vault ZIP archive with `/Walks`, `/Species`, `/Media`, and `treads-backup.json` at root.
  - **D-14:** Rich Obsidian-native YAML properties with Dataview and Map plugin compatibility.
  - **D-15:** Full 1024px JPEGs and recorded WebM audio clips in `/Media` with sanitized slug filenames referenced via `![[...]]`.
  - **D-16:** Dedicated `/settings` route with storage persistence status, audio/haptic preferences, instant export download, and a two-step Danger Zone modal for IndexedDB reset.
