# Plan 05-01: Daily Species Hunt Engine, Celebration Dialog & Life List Collection

## Objective
Build the gamified nature discovery engine and permanent naturalist collection: implement the deterministic daily species hunt rules generator (`HUNT-01`), automated day-wide progress matching with celebration modal dialog (`HUNT-02`), and the responsive Life List collection screen (`LIFE-01`) on `/collection` featuring category pills, search/sort, canonical de-duplicated specimen cards, and field notebook empty states.

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Design Contract:** Follow Tangerin Dream tokens, 4-multiple spacing scale, 4 font sizes, and reserved accent usage in `05-UI-SPEC.md`.
- **Locked Decisions (per CONTEXT.md):**
  - **D-01:** Tiered multi-target challenge deterministically hashed from `YYYY-MM-DD` with individual progress pips.
  - **D-02:** Day-wide automatic matching across all walk sessions (00:00 to 23:59 local time).
  - **D-03:** Celebratory modal dialog with stamp animation, audio chime (if sound enabled), and haptic pulse.
  - **D-04:** Hero card on `/collection` + compact expandable top HUD pill during `/walk`.
  - **D-05:** Horizontal scrollable category filter pills with live counts.
  - **D-06:** Canonical species cards with `Seen Nx` encounter counts.
  - **D-07:** Real-time text search and sort dropdown (`Most Recent`, `Most Seen`, `Alphabetical A–Z`).
  - **D-08:** Evocative field notebook empty state with warm serif prose and `Start Walk` button.

    1. Create lib/hunt.ts:
       - Define types:
         ```ts
         export type HuntTarget = {
           id: string;
           kind: 'tree' | 'flower' | 'plant' | 'bird' | 'insect' | 'fungus' | 'other';
           count: number;
           label: string;
         };
         export type DailyHunt = {
           id: string;
           date: string; // YYYY-MM-DD
           title: string;
           description: string;
           targets: HuntTarget[];
         };
         export type HuntProgress = {
           hunt: DailyHunt;
           completed: boolean;
           targetProgress: Array<{
             target: HuntTarget;
             current: number;
             completed: boolean;
           }>;
           matchingEntryIds: string[];
         };
         ```
       - Implement 32-bit FNV-1a hash function `hashDateString(dateStr: string): number`.
       - Create curated challenge rules catalog (14+ distinct multi-target goals spanning trees, flowers, plants, birds, insects, and fungi).
       - Implement `getDailyHunt(dateStr?: string): DailyHunt` using local date string `YYYY-MM-DD` (defaults to `new Date().toLocaleDateString('en-CA')`).
       - Implement `evaluateHuntProgress(hunt: DailyHunt, entries: Entry[]): HuntProgress`:
         - Filters entries created on `hunt.date` (between start of day and end of day local time) with `status === 'confirmed'`.
         - Counts matches per target `kind`, computes progress pips, and determines overall completion boolean.
    2. Create scripts/test-hunt-engine.ts:
       - Asserts `getDailyHunt('2026-10-08')` yields deterministic challenge attributes.
       - Asserts `evaluateHuntProgress` correctly ticks pips when matching entries are provided.
       - Verifies that entries outside today's date window are ignored.
    3. Run `npx tsx scripts/test-hunt-engine.ts` to verify.
