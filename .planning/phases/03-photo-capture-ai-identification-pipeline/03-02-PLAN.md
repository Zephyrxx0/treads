# Plan 03-02: `/api/identify` Route with Gemini Flash Multimodal, Wikipedia Taxon Verification & Candidate Picker Drawer

## Objective
Implement the server-side AI identification pipeline and in-walk candidate selection interface: create the `/api/identify` endpoint leveraging `@ai-sdk/google` (Gemini Flash multimodal vision with mock fallback), verify taxonomic legitimacy against the Wikipedia Action API (`redirects=1`), display candidates in an interactive bottom sheet drawer on `/walk` with confidence chips (`Likely`, `Possible`, `Unsure`), and handle honest refusals (inanimate objects/humans) with an educational card.

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Locked Decisions (per CONTEXT.md):**
  - **D-05:** Bottom sheet drawer on `/walk` presenting up to 3 candidates as interactive cards with confidence badges and 1-tap selection to confirm.
  - **D-06:** Educational refusal card for non-organisms or human portraits ("We noticed an inanimate object or person. Treads tracks living organisms in nature") with "Retake Photo" and secondary "Save as Unidentified Note".
  - **D-07:** Low-confidence identification UX: candidates with all "Unsure" ratings display amber badges with an explicit "None of these / Save as Unidentified" button alongside "Retake".
  - **D-08:** Specialized model pairing: Gemini Flash (multimodal) for `/api/identify` photo organism candidate generation with graceful mock fallback if API key is absent.
  - **D-09:** Wikipedia taxon verification: query Wikipedia Action API with `redirects=1` and verify biological taxonomy markers/categories (`species microformats`, `Taxobox`, italic display titles); verified species receive green badge.
- **Component Mandate:** Strictly compose readymade shadcn Base UI primitives (`Sheet`, `Card`, `Badge`, `Button`, `Dialog`).

    1. Create lib/wikipedia.ts:
       - Define `WikipediaTaxonResult`: `{ verified: boolean; canonicalTitle: string; description?: string; pageId?: number }`.
       - Implement `verifyWikipediaTaxon(title: string): Promise<WikipediaTaxonResult>`:
         - Queries `https://en.wikipedia.org/w/api.php?action=query&titles=${encodeURIComponent(title)}&redirects=1&prop=categories|pageprops&format=json&origin=*`.
         - Inspects categories for biological microformats/keywords (`species`, `taxa`, `Flora of`, `Fauna of`, `plants`, `birds`, `insects`, `fungi`, `animals`).
         - Inspects `displaytitle` for `<i>` formatting (botanical/zoological convention).
         - Inspects `wikibase-shortdesc` for taxonomic keywords.
         - Returns `verified: true` if biological indicators are present, `false` otherwise.
    2. Create scripts/test-wikipedia-taxon.ts:
       - Tests biological species: `Quercus alba` (White Oak), `Passer domesticus` (House Sparrow) -> asserts `verified === true`.
       - Tests non-biological subjects: `Bicycle`, `Coffee cup` -> asserts `verified === false`.
       - Tests redirect resolution: e.g. `American robin` -> resolves canonical title `American robin` / *Turdus migratorius*.
  </action>
