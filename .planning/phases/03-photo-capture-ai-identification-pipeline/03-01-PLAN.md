# Plan 03-01: Camera Capture Shutter, HTML5 Canvas EXIF Stripper, Local Thumbnail Generation & Preview Sheet

## Objective
Implement the client-side photo capture and compression foundation: wire the camera shutter button on `/walk` to trigger the native device camera, re-rasterize captured photos on HTML5 Canvas to strip 100% of EXIF/GPS hardware tags and resize to max 1024px JPEG (~140KB) plus a 160px thumbnail (~15KB), store both assets in Dexie IndexedDB with coordinates before network transit, and display an instant preview bottom sheet with "Retake" and "Identify Organism" actions.

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Locked Decisions (per CONTEXT.md):**
  - **D-01:** Native OS camera trigger via `<input type="file" capture="environment">` to leverage native auto-focus, HDR, and macro focus with zero WebRTC permission friction.
  - **D-02:** Instant preview bottom sheet on `/walk` with captured photo, "Retake" and "Identify Organism" buttons, and subtle "Stripping EXIF & optimizing..." badge.
  - **D-03:** Dual storage in Dexie IndexedDB: store 1024px photo (~150KB) as Blob + generate lightweight 160px thumbnail (~15KB) for instant map pins and journal list rendering.
  - **D-04:** Universal file picker fallback for desktop browsers and dev testing (JPG, PNG, HEIC, WebP) running through the identical Canvas EXIF stripping pipeline.
- **Component Mandate:** Strictly compose readymade shadcn Base UI primitives (`Sheet`, `Button`, `Badge`, `Card`).

       - `processCapturedImage(file: File | Blob): Promise<{ photoBlob: Blob; thumbnailBlob: Blob; width: number; height: number; sizeBytes: number }>`:
         - Uses `createImageBitmap(file)` (which respects native EXIF orientation in modern browsers).
         - Downscales to max 1024px dimension for photo, exports via `canvas.toBlob('image/jpeg', 0.82)` to strip all EXIF/GPS tags.
         - Downscales to max 160px dimension for thumbnail, exports via `canvas.toBlob('image/jpeg', 0.80)`.
       - `blobToBase64(blob: Blob): Promise<string>`: helper for converting Blob to base64 string for API payloads.
    3. Create scripts/test-camera-pipeline.ts:
       - Unit tests `calculateDimensions` with landscape (4032x3024 -> 1024x768), portrait (3024x4032 -> 768x1024), square (2000x2000 -> 1024x1024), and smaller images (600x400 -> 600x400).
