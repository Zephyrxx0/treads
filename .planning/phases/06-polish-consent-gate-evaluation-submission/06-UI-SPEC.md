## UI Considerations

Applicable state considerations resolved: 5 covered, 2 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| First-time onboarding | `ConsentModal` | ✅ covered | Renders unclosable blocking overlay until user clicks 'I Understand & Accept', then persists acceptance to IndexedDB. |
| Permission denial fallback | Camera/Mic/GPS sheets | ✅ covered | Non-blocking inline banner with guidance and immediate manual fallback (file input for photo, text area for voice). |
| Accessibility / Reduced Motion | `TegakiText` | ✅ covered | If `prefers-reduced-motion` is active, handwriting animation duration is 0ms, rendering instant static text. |
| Autoplay policy | `Cuelume` Web Audio | ✅ covered | AudioContext initialized/resumed only on explicit user click/tap, avoiding browser console autoplay warnings. |
| Muted state | Settings toggles | ✅ covered | Sound chimes default to OFF; haptics default to ON; respects user toggles in `db.settings`. |
| Network latency | `/eval` batch runner | 🧪 backstop | Progress bar with animated percentage pulse and disabled button state during evaluation execution. |
| Mobile viewport responsiveness | Modal & HUD sheets | 🧪 backstop | `max-h-[90vh]` with overflow-y-auto and touch padding prevents clipping on Android mobile viewports. |
