# Plan 06-01: Tegaki Handwriting Animation, Cuelume Web Audio Chimes, Haptics & Consent Gate

## Objective
Implement sensory polish and privacy enforcement: build the progressive Tegaki handwriting reveal component with Google Font Caveat fallback (`DSGN-03`), synthesize gentle dual-oscillator Cuelume Web Audio chimes for capture and hunt win (`DSGN-04`), trigger native device haptic vibrations (`DSGN-05`), and enforce the global first-run consent modal gate with `navigator.storage.persist()` and non-blocking permission fallbacks (`CONS-01`, `CONS-02`, `CONS-03`, `CONS-04`).

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Design Contract:** Follow Tangerin Dream tokens, 4-multiple spacing scale, typography hierarchy, and Caveat font token in `06-UI-SPEC.md`.
- **Locked Decisions (per CONTEXT.md):**
  - **D-01:** SVG path stroke dashoffset / cursive draw over ~1.2s.
  - **D-02:** Google Font Caveat cursive fallback with instant opacity reveal when `prefers-reduced-motion` is active.
  - **D-03:** Scope: Landing hero headline and Fact Card confirmed specimen titles; plays once on view entrance.
  - **D-04:** Dynamic text rendering: SVG text stroke with dashoffset reveal + Caveat cursive styling scaling to arbitrary species names.
  - **D-05:** Dual-sine / triangle warm chime with exponential decay envelope (gentle brass/field bell feel).
  - **D-06:** 2 events: Specimen Confirmation (E5-G#5) & Daily Hunt Completion (C5-E5-G5-C6).
  - **D-07:** Tactile pair: crisp 25ms tick on capture/selection, and resonant double pulse [40ms, 60ms, 80ms] on confirmation/hunt win.
  - **D-08:** Audio chimes OFF by default, Haptics ON by default; lazy `AudioContext` resume on first user interaction.
  - **D-09:** Strict app-wide modal overlay on first visit blocking interaction until accepted.
  - **D-10:** Semver string `"1.0.0"` & timestamp in `db.settings`.
  - **D-11:** Non-blocking inline banner with guidance and immediate manual fallback (file picker, text note) on permission denial.
  - **D-12:** Silent request on consent click; live status badge in `/settings` with one-tap retry button.
