3. Primary action button ("Start Walk")
4. Active follow-camera FAB focus ring and compass heading needle

---

## Visual Hierarchy & Focal Points

1. **Primary Focal Point:** The interactive MapLibre vector map canvas with user terracotta location puck and live trail breadcrumb polyline.
2. **Secondary Focal Point:** Top floating glassmorphism HUD bar displaying elapsed duration, distance, and GPS signal quality pill.
3. **Tertiary Focal Point:** Floating bottom dock housing the hold-to-confirm "End Walk" action and future camera trigger.
4. **Control Stack:** Vertical right-margin floating stack providing one-handed thumb access to Recenter FAB, Zoom +/- buttons, and North compass reset.

## UI Considerations

Applicable state considerations resolved across Phase 2 surfaces:

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Pre-walk Landing Card (E1) | ✅ covered | Displays "Ready to Explore" heading, mode badge, and primary "Start Walk" CTA. |
| loading | Map Viewport (E2) | ✅ covered | OpenFreeMap vector style loads with canvas skeleton; background defaults to theme surface token. |
| error | Location Banner (E8) | ✅ covered | Displays actionable banner "Location signal unavailable" with "Re-enable Location" button. |
| populated | Map Viewport & Trail (E2) | ✅ covered | Renders continuous 4px terracotta polyline, user beacon with pulsing ring, and "Approximate path" legend. |
| partial | HUD Pill (E3) | ✅ covered | Shows amber chip "Weak GPS ±Xm" while quietly pausing duplicate breadcrumbs until accuracy < 35m. |
| overflow | Summary Sheet (E6) | ✅ covered | Bottom drawer sheet auto-fits map trail bounds into view; stats grid scrolls gracefully on small mobile screens. |
| zero-one-many | Summary Sheet (E6) | ✅ covered | Species count displays singular/plural metric ("0 species recorded" for Phase 2). |
| long-text | HUD Pill (E3) | 🧪 backstop | Distance formatting automatically scales from meters ("450 m") to kilometers ("3.24 km") with tabular digits. |
| loading | Pre-walk GPS Fix (E1) | ✅ covered | Shows pulsing location target icon while browser acquires first high-accuracy GPS fix. |
| error | Short Walk Dialog (E7) | ✅ covered | Guards walks under 1 minute or under 25 meters with explicit "Discard Walk" vs "Save Anyway" options. |
