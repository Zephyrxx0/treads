# Plan 04-02: Fact Card TTS Narration with Speech Cache & OpenRouteService Pedestrian Loop Routing

## Objective
Implement spoken fact card narration and pedestrian loop discovery: build `/api/speak` (calling ElevenLabs TTS with calm nature guide voice) with browser `speechSynthesis` fallback, client-side SHA-256 text-hash caching in Dexie `speechCache` with LRU pruning, an interactive inline audio pill on fact cards, and pre-walk pedestrian loop route suggestions via `/api/route` (OpenRouteService pedestrian round-trip) with MapLibre dashed guidelines, quiet off-route guidance, and synthetic circular loop fallbacks.

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Locked Decisions (per CONTEXT.md):**
  - **D-03:** Drops small terracotta audio pin on MapLibre trail at recording coordinate; summary sheet lists all notes with playable audio snippets.
  - **D-09:** Fact card "Listen" narrates organism name intro, summary paragraph, and all numbered grounded facts in natural storytelling flow.
  - **D-10:** Inline fact-card audio pill replaces "Listen" with Play/Pause, scrubber progress bar, elapsed time, and 1x/1.2x speed toggle.
  - **D-11:** Warm calm nature-documentary voice for ElevenLabs; seamless fallback to browser `speechSynthesis` with subtle "Device voice" chip.
  - **D-12:** SHA-256 hash of `text + voiceId` stored as Blob in Dexie `speechCache` with LRU pruning (up to 50 clips or 50MB) for instant offline replay.
  - **D-13:** Pre-walk start drawer on `/walk`: choose "Free Walk" or "Loop Route (1km / 2km / 3km)" to preview calculated route before starting.
  - **D-14:** Suggested loop rendered as dashed terracotta polyline (`#F35C2B`, 0.6 opacity) with directional indicators; active GPS trail paints glowing solid trail on top.
  - **D-15:** Gentle non-intrusive off-route guidance: no jarring alarms; quiet "Off route" badge on HUD with 1-tap "Clear Route" button.
  - **D-16:** Graceful ORS fallback: if ORS key missing or offline, show calm notice with synthetic circular test loop and 1-tap "Start Free Walk".

       - Checks `process.env.ORS_API_KEY`:

         - If key absent or request fails: generates synthetic geometric loop via `generateSyntheticLoop()` and returns GeoJSON Feature with `fallback: true`.

### Threats & Mitigations
- **T-04-04 (API Quota exhaustion):** Rapid TTS requests consume ElevenLabs credit quota. Mitigation: Daily rate limiting (40/day) on `/api/speak` + client SHA-256 Dexie caching stops all redundant calls.
- **T-04-05 (IndexedDB storage bloat):** Unlimited speech audio accumulation exceeds browser storage limits. Mitigation: LRU pruning restricts cached clips to 50 items (~25MB max).
- **T-04-06 (Denial of Service via Route queries):** Malicious inputs to `/api/route`. Mitigation: Strict Zod validation on lat/lng coordinates and distance constraints (1000, 2000, 3000m only) + rate limiting.
</threat_model>
