# Plan 04-01: Voice Recorder, Live Waveform, ElevenLabs Scribe STT with Web Speech Fallback & Dexie Notes Persistence

## Objective
Implement hands-free nature journaling: build the unified hold-or-tap audio recording engine with real-time Web Audio `AnalyserNode` live waveform visualization, 60-second circular timer limit, slide-to-cancel gestures, `/api/transcribe` ElevenLabs Scribe STT route with browser Web Speech API fallback, post-recording transcript review bottom sheet, and Dexie `notes` persistence attached to walks and organism finds.

## User Rules & Context
- **SHELL:** zsh
- **Package Manager:** pnpm
- **Locked Decisions (per CONTEXT.md):**
  - **D-01:** Dual recording triggers: mic button in `/walk` dock attaches to walk (`walkId`); "Add voice note" button on `/entry/[id]` attaches to entry (`entryId`).
  - **D-02:** Bottom sheet review drawer displaying audio playback, detected language badge, and editable transcript textarea with "Save Note" and "Discard".
  - **D-04:** Store compressed audio (WebM/Opus) + transcript in Dexie `notes` table (~30-50KB per 60s note).
  - **D-05:** Unified smart gesture: short tap toggles hands-free recording on/off; continuous press-and-hold records until release.
  - **D-06:** Circular terracotta progress ring around mic with MM:SS counter, amber warning at 50s, auto-stop at 60.0s.
  - **D-07:** Dynamic vertical bar equalizer with 24-32 responsive terracotta bars (`#F35C2B` gradient).
  - **D-08:** Slide-to-cancel gesture during hold; red trash button during hands-free; friendly browser mic permission recovery notice.

### Threats & Mitigations
- **T-04-01 (Microphone stream leak):** Hardware microphone remains active if component unmounts mid-recording. Mitigation: `stopMediaStream` cleanly invokes `track.stop()` on all audio tracks on cancel, finish, or unmount.
- **T-04-02 (API Key exposure):** Client exposes `ELEVENLABS_API_KEY`. Mitigation: Audio is transmitted via `/api/transcribe` Next.js route; client never accesses API key.
- **T-04-03 (Storage exhaustion):** Massive audio blobs overflow mobile IndexedDB quota. Mitigation: Recorded audio is stored as WebM/Opus compressed blob (~30-50KB/min) with max 60s ceiling.
</threat_model>
